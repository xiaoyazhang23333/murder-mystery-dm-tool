# 剧本杀 DM 开本工具生成器 🎭

> 把任意剧本杀素材文件夹，一键变成一个**单文件 HTML 开本助手**——主持人（DM）打开浏览器就能开团。

这是一个 AI Agent Skill：你只需把剧本杀素材包丢给 AI，它会自动完成素材整理、手册解读、流程编排，最终生成一个功能完整的 DM 工具页面。

## ✨ 生成的 DM 工具包含什么

| 页面 | 功能 |
|------|------|
| 🏠 首页 | 无剧透流程导航，严格隐藏"凶手/真相/手法"等剧透词汇 |
| 📖 分发剧本 | 角色卡片 + 剧本 PDF 下载 |
| 🔍 线索搜证 | 多轮次搜证管理、区域分组、发放标记 |
| ⚡ 突发事件 | 童谣、特殊机制、触发时机提醒 |
| 📚 资料参考 | 人物简介 / 地点说明 / 游戏规则（玩家可见） |
| 🕵️ 真相复盘 | 案件真相、结局条件（DM 专用剧透区） |
| 📦 素材总览 | 密码保护，预览与下载全部素材 |

另外内置 **15/30 分钟计时器**，UI 采用 shadcn/ui 浅色主题，清爽不花哨。

## 🚀 怎么用

### 方式一：作为 AI Skill 使用（推荐）

1. 将本仓库的 `SKILL.md`、`scripts/`、`assets/` 安装到你的 Agent skills 目录（如 `~/.agents/skills/murder-mystery-dm-tool/`）
2. 对 AI 说：**"帮我做一个剧本杀 DM 工具，素材在 xxx 文件夹"**
3. AI 会按 6 个阶段与你确认后自动生成：

```
素材扫描 → 读取组织者手册 → 素材整理 → 内容构建 → HTML 生成 → 交付
```

### 方式二：直接运行脚本

```bash
# 扫描素材结构并生成报告
python scripts/generate_dm_html.py <素材文件夹> --report

# 根据配置生成 DM 工具 HTML
python scripts/generate_dm_html.py <素材文件夹> -c config.json
```

输出：`{游戏名称}-DM工具.html`，用浏览器直接打开即可开团。

## 📁 素材文件夹怎么放

**原始素材**（无需整理，AI 会帮你处理）：

```
素材文件夹/
├── 组织者手册/     # 分页扫描图
├── 剧本/角色A/     # 角色剧本分页
├── 线索/           # 线索正反面图片
└── 地图/
```

**已整理素材**（直接生成）：

```
素材文件夹/
└── 准备好的素材/
    ├── 组织者手册.pdf
    ├── 角色A.pdf
    └── 切分后的线索/
```

## ⚙️ 自定义配置（config.json）

游戏标题、角色身份、搜证轮次与规则、流程阶段、突发事件、真相复盘、素材页密码等都可以通过 `config.json` 配置，完整字段说明见 [SKILL.md](./SKILL.md)。

## 🛠 依赖

- Python 3
- `pymupdf`（PDF 拼接，可选）
- `Pillow`（图片处理，可选）
- 生成的 HTML 使用 Tailwind CSS CDN，联网打开效果最佳

## 💡 为什么做这个

剧本杀主持人开本前的准备工作琐碎又容易出错：整理剧本、切分线索、记流程、掐时间……这个工具把这些工作压缩成"**丢素材 → 等确认 → 拿 HTML**"三步，让 DM 把时间花在带场和氛围上，而不是翻文件夹。
